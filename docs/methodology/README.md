# Productive Agent Layer

Freegate встраивает **методологию инженерной дисциплины** прямо в запросы к
провайдеру — так что любой OpenAI-совместимый клиент (opencode, Cursor, чистый
чат) получает ответы как от опытного инженера без изменений на стороне клиента.

Это текстовый слой. Файловые инструменты, субагенты и цикл
тест→код работают на стороне агента; здесь — только **стиль и дисциплина ответа**.

## Слои

| Слой | Файл | Что делает |
|---|---|---|
| Классификатор задачи | `lib/taskclassify.js` | Определяет тип запроса: `coding / reasoning / search / chat` (без LLM, эвристики по последнему user-сообщению) |
| Методолог | `lib/methodology.js` | Возвращает короткий системный промпт под категорию и вставляет его в диалог |
| Роутинг по задаче | `server.js` | Бустит вес моделей подходящей категории (`coding→coding`, `reasoning→reasoning`, `chat/search→general`), не исключая fallback |
| Телеметрия | `lib/contextstats.js` | Считает частоту категорий (`tasks`), видно в `/health` и `tools/context-diag.js` |

## Конфигурация

```json
{ "methodology": { "enabled": true } }
```

По умолчанию включён. `enabled: false` отключает методолог и роутинг-буст.

## Методолог для каждой категории

- **coding** — краткий план перед кодом, предложить тест, указать файл/строку.
- **reasoning** — рассуждать пошагово, показать допущения.
- **search** — короткий фактологичный ответ, не выдумывать источник.
- **chat** — по существу и кратко.

## Откуда методология (атрибуция)

Краткие промпты-методологи написаны **по мотивам** проекта
[superpowers](https://github.com/obra/superpowers) (автор Jesse Vincent,
лицензия **MIT**). Набор навыков TDD, планирования, систематического дебага и
код-ревью то же использовать как ресурс. Полные скиллы работают в агентном цикле
(у superpowers — для Claude Code / Gemini / opencode); здесь — производный
сжатый текст для дисциплины ответа.

### Использование superpowers-навыков в агентном цикле

Для полноценной работы навыков (тест до кода, планы, субагенты) подключите
[opencode](https://opencode.ai) и установите плагин superpowers — Freegate уже
выступает как OpenAI-совместимый провайдер для него.
